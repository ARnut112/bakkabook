# บริษัทขนส่ง เลขพัสดุ และการยืนยันรับสินค้า

## ติดตั้ง

1. รัน `supabase/shipping.sql` ทั้งไฟล์ใน Supabase SQL Editor (หลัง `orders.sql` ของระบบเดิม)
2. Deploy โค้ดหน้าเว็บเวอร์ชันใหม่ขึ้น Vercel

ไม่ต้องแก้ Secrets หรือ deploy ฟังก์ชัน LINE ใหม่ ไม่มีการส่งข้อความ LINE เพิ่มตอนจัดส่ง/รับสินค้า
ไฟล์ SQL รันซ้ำได้และไม่ลบรายการเดิม หากรัน `orders.sql` ซ้ำภายหลัง ให้รัน `shipping.sql` ต่อท้ายเพื่อคืนฟิลด์ติดตามใน RPC

## ใช้งาน

- หลังร้าน: สำหรับรายการยืนยันการชำระแล้ว กรอกบริษัทขนส่งและเลขพัสดุ เลือกสถานะจัดส่งแล้ว แล้วบันทึก ช่องบริษัทขนส่งเป็นข้อความอิสระ รองรับบริษัทอื่นได้
- แก้เลขพัสดุได้ขณะที่ยังจัดส่งอยู่ เมื่อปิดคำสั่งซื้อแล้วจะไม่แก้ข้อมูลจัดส่งผ่านช่องนี้
- ลูกค้า: ค้นหาด้วยเบอร์โทรในหน้าติดตาม เห็นบริษัทขนส่งและเลขพัสดุที่เลือกคัดลอกได้
- ปุ่มได้รับสินค้าแล้วแสดงเฉพาะรายการสถานะจัดส่งแล้ว มีข้อความยืนยันก่อนปิดรายการ
- เมื่อยืนยัน รายการเปลี่ยนเป็น completed และย้ายไปประวัติคำสั่งซื้อ ยังเปิดดูเลขพัสดุได้
- ออเดอร์ที่จัดส่งก่อนติดตั้งยังยืนยันรับได้ แต่จะไม่มีข้อมูลเลขพัสดุจนแอดมินเติมให้

## การตรวจสอบ

SQL ตรวจสิทธิ์แอดมินก่อนบันทึกจัดส่ง และตรวจเลขออเดอร์/เบอร์โทรตามรูปแบบระบบเดิมก่อนยืนยันรับ
การค้นหาด้วยเบอร์โทรยังเป็นรูปแบบเดิม ไม่ใช่การยืนยันตัวตนด้วย OTP หากเพิ่มบัญชีลูกค้าภายหลังควรเปลี่ยนเป็นตรวจเจ้าของบัญชีด้วย
ยืนยันรับได้เฉพาะ shipped และใช้ row lock ป้องกันชนกับการเปลี่ยนสถานะ ไม่ปรับยอดชำระหรือสต็อก การกดซ้ำไม่มีผลเพิ่ม

ทดสอบฐานข้อมูลจำลองใน `tests/shipping.test.cjs` และเบราว์เซอร์ด้วยข้อมูลจำลอง ไม่มีการจัดส่งหรือปิดคำสั่งซื้อจริงระหว่างพัฒนา
