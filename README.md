# Bakkabook

ร้านหนังสือ 3 หน้า ออกแบบใหม่ในโทนครีม เขียวเข้ม และส้มอิฐ พร้อมปกหนังสือภาพประกอบที่สร้างสำหรับโปรเจกต์นี้

## เปิดใช้งาน

ผ่าน Laragon: เปิด `http://localhost/Shopna/` เมื่อเว็บเซิร์ฟเวอร์ทำงาน หรือใช้ Node.js 20 ขึ้นไป:

```powershell
node server.mjs
```

เปิด `http://127.0.0.1:8085` ไม่ต้องติดตั้งแพ็กเกจสำหรับเว็บ

## หน้าต่าง ๆ

- `index.html` หน้าร้าน: หนังสือ 12 เล่ม ค้นหาชื่อ/ผู้เขียน กรองหมวดหมู่ เรียงราคา รายการคัดสรร และชั้นหนังสือที่บันทึกไว้
- `product.html?id=book-01` รายละเอียด: ราคา เรื่องย่อ ข้อมูลเล่ม แกลเลอรีรูป สถานะสต็อก และหนังสือที่เกี่ยวข้อง
- `admin.html` หลังร้าน: เพิ่ม แก้ไข ลบ อัปโหลดรูปสูงสุด 4 รูป ราคา สต็อก ฉบับร่าง/เผยแพร่ และผู้ช่วยกรอกข้อมูล

รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์ ใช้ HTML, CSS และ Vanilla JavaScript

## โหมดตัวอย่าง

เปิดใช้ทันทีโดยไม่ต้องสมัครบริการ ข้อมูลตัวอย่างเป็นหนังสือสมมติ การเปลี่ยนแปลงและชั้นหนังสือเก็บใน localStorage ของเบราว์เซอร์ ข้อมูลไม่ส่งออกไปและไม่แชร์ข้ามเครื่อง ปุ่มลองข้อมูล AI เป็นการสาธิตแบบเตรียมข้อมูลไว้ ไม่ได้วิเคราะห์ภาพจริง

ควรเปิดทุกหน้าผ่าน origin เดียวกัน เช่น `http://localhost/Shopna/` การเปลี่ยนไปใช้โดเมนอื่นหรือโหมดไม่ระบุตัวตนจะเป็นพื้นที่ข้อมูลคนละชุด

## เชื่อมต่อบริการจริง

ดู `SETUP.md` สำหรับขั้นตอนทีละข้อ:

- `config.js` ใส่ Supabase URL และ publishable / anon key
- `supabase/schema.sql` สร้างตาราง สิทธิ์ RLS และ Storage
- `supabase/functions/book-assistant/index.ts` ผู้ช่วยอ่านปกและค้นข้อมูลหนังสือด้วย Gemini
- Gemini API key อยู่ใน Supabase Edge Function Secrets เท่านั้น

เมื่อเชื่อม Supabase หน้าแอดมินต้องเข้าสู่ระบบด้วยบัญชีที่ได้รับสิทธิ์ ข้อมูลจริงเริ่มจากฐานข้อมูลว่าง

## โครงสร้างไฟล์

```text
index.html / product.html / admin.html
config.js
assets/
  css/style.css
  js/data.js       หนังสือตัวอย่าง
  js/store.js      ข้อมูล localStorage / Supabase / Auth
  js/common.js     ส่วนแสดงผลร่วม
  js/home.js       หน้าร้าน
  js/product.js    รายละเอียด
  js/admin.js      หลังร้าน
  covers/         ปกหน้าและหลัง 24 ภาพ
supabase/         SQL และ Edge Function
server.mjs        เซิร์ฟเวอร์ในเครื่อง
SETUP.md          คู่มือเชื่อมต่อ
```

## ทดสอบ

```powershell
node --test tests/store.test.cjs
```

ทดสอบข้อมูล การค้นหา กรอง เรียงราคา รายการโปรด การบันทึก/แก้ไข/ลบ ฉบับร่าง ข้อมูลไม่ถูกทำลายเมื่อพื้นที่เต็ม และสัญญาการเรียก API ด้วยเครือข่ายจำลอง

`tests/browser.cjs` เป็นชุดทดสอบเบราว์เซอร์เพิ่มเติม ต้องมี Playwright และเบราว์เซอร์ที่รองรับ โดยตั้ง `PLAYWRIGHT_PATH` เป็นที่อยู่โมดูลที่ติดตั้ง และ `BROWSER_PATH` เป็นที่อยู่ Chromium/Edge หากไม่ได้ใช้ browser bundle ของ Playwright แล้วรัน `node tests/browser.cjs` ชุดทดสอบเปิดเซิร์ฟเวอร์และโปรไฟล์ชั่วคราวเอง บันทึกภาพลง `test-results/`

Supabase RLS, Storage และ Gemini จริงต้องตรวจซ้ำหลังสร้างโปรเจกต์และใส่ค่าตาม SETUP.md เพราะชุดทดสอบในเครื่องไม่ใช้บัญชีจริง

รันชุดทดสอบข้อมูลและ Edge Function จำลองทั้งหมดด้วย `npm test` หรือ `node --test tests/*.test.cjs` โดยใช้ Node.js 22.13 ขึ้นไป (ทดสอบในเครื่องนี้ด้วย Node.js 24) ชุด Edge Function จำลองตรวจสิทธิ์ผู้ใช้และการจัดการข้อมูลค้นหา ไม่เรียก Gemini จริง
